# Generales Baseball Academy

Aplicación web móvil (React + Vite + Supabase) para consultar y administrar jugadores.

## Ejecutar localmente

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
```

La carpeta `dist/` contiene la versión lista para publicar.

## Seguridad

La app usa una Publishable Key pública. Los permisos de lectura/escritura se controlan en Supabase mediante RLS.
